📊 Walidacja modelu (backtest)
Pobierz cały zeszły sezon z FootyStats, run model na każdym meczu (PRE-MATCH ze stale state), porównaj predykcje z faktycznymi wynikami. Wynik: ile picks model by zrobił, hit rate, ROI, calibration. Twarde dane czy model bije bukmachera.
Ustawienia
Maksymalna suma stawek na dzień. Powyżej limitu — confirm dialog. Default 20% (= 200 zł przy 1000 zł bankrollu).
Każdy pick dostanie button "Otwórz @ bukmacher" → nowa zakładka. Wpisz np. https://bc.game lub https://www.betclic.pl
Stała mnożenia Kelly. Default 0.25 = ćwiartka Kelly (konserwatywne). 1.0 = pełny Kelly (agresywne).
Pokazuje WYŁĄCZNIE mecze z ~30 top lig (UCL/UEL/UECL, top 5 European, Eredivisie, Primeira, Süper Lig, Ekstraklasa, MLS, Brazil Serie A, Argentyna, etc.). Filtruje: NI Premier Intermediate, Scottish Championship, Polish III liga, Georgian Erovnuli, UAE League Cup, U-divisions, lower-tier women, etc. Apliowany WSZĘDZIE (LIVE, Wszystkie live, Dziś, Moje bety = wyjątek bo user explicitly tracks).
